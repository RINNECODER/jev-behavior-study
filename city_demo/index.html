What the model can see — and what code does

Structured modes receive vehicle telemetry, nearby traffic, light states, the road grid and destination coordinates. This is simulator-provided perception. Direct mode executes the selected steering and pedals. Maneuver mode adds a lane-following and speed controller. Neither mode receives an optimal route or a recommended action.

Real time keeps the city moving while Jev responds. Paused mode freezes the whole world during the API wait and advances 0.6 seconds after the decision. Both stop at the first collision or after 160 decisions. Native screenshot driving is unavailable until a supported image interface is verified; capturing an image does not send it to Jev.

Keyboard: W / ↑ accelerate, S / ↓ brake, A / ← steer left, D / → steer right. Manual mode uses real time. A destination counts when the car is within 6 metres and below 2 m/s. Explore requires 150 metres and two intersections in 90 seconds. This is a simplified simulator, not a real-world driving evaluation.
